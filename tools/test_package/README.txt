KVM დემო — კავშირის პირველი ტესტი (2 კომპიუტერი)
=====================================================

რას ვამოწმებთ: ორი კომპიუტერი ქსელით უკავშირდება ერთმანეთს, ცვლიან hello-ს და ყოველ წამში
ping-ს. მაუსი და ვიდეო ჯერ არ არის — მხოლოდ კავშირი.

Visual Studio და სხვა არაფერი არ უნდა დააყენოთ — exe-ები დამოუკიდებელია.

მომზადება
---------
1. ორივე კომპიუტერი ერთ Wi-Fi-ზე / ერთ რაუტერზე. სტუმრის (guest) Wi-Fi ხშირად კრძალავს
   მოწყობილობებს შორის კავშირს — ასეთზე ნუ სცდით. ტელეფონის hotspot-ზე იმუშავებს, მაგრამ ნელა.
2. ორივეზე ეს საქაღალდე გახსენით (zip-იდან ამოიღეთ, zip-ის შიგნიდან ნუ გაუშვებთ).
3. გადაწყვიტეთ, ვინ არის HOST (A) და ვინ CLIENT (B).

HOST კომპიუტერზე (A)
--------------------
1. ორჯერ დააწკაპუნეთ 1_allow_firewall.cmd → Windows ითხოვს ადმინის უფლებას → Yes.
   (ერთხელ საკმარისია.)
2. ორჯერ დააწკაპუნეთ 2_run_host.cmd.
   ზემოთ დაიწერება ამ კომპიუტერის IP მისამართ(ებ)ი, მაგ. 192.168.1.23 (Wi-Fi).
   ეს IP უთხარით მეორეს.
   თუ Windows Firewall-ის ფანჯარა გამოჩნდა → Allow.

CLIENT კომპიუტერზე (B)
----------------------
1. ორჯერ დააწკაპუნეთ 3_run_client.cmd → შეიყვანეთ HOST-ის IP → Enter.

წარმატება ასე გამოიყურება
-------------------------
HOST-ზე:   client 'DEMETRE-PC' connected from 192.168.1.40:...: screen 1920x1080, dpi scale 1.25
           link: rtt 2.31 ms, clock offset ...      (ყოველ 5 წამში)
CLIENT-ზე: connected to host 192.168.1.23:50500
           link: rtt 2.40 ms, clock offset ...

rtt ჩაიწერეთ — ეს არის ქსელის დაყოვნება (რაუტერზე ჩვეულებრივ 1–10 ms).

დამატებითი შემოწმებები (თითო 1 წუთი)
--------------------------------------
ა) CLIENT-ის ფანჯარა დახურეთ → HOST-ზე უნდა დაიწეროს "disconnected" / "session ended".
   ხელახლა გაუშვით 3_run_client.cmd → ისევ "connected".
ბ) HOST-ის ფანჯარა დახურეთ → CLIENT წერს "reconnecting in 1 s..." ყოველ წამში.
   ხელახლა გაუშვით 2_run_host.cmd → CLIENT თავისით უნდა დაუკავშირდეს.
გ) Wi-Fi გამორთეთ CLIENT-ზე 10 წამით → HOST ~5 წამში წერს "no data ... dropping connection".
   Wi-Fi ჩართეთ → CLIENT თავისით უბრუნდება.

თუ არ უკავშირდება
-----------------
1. CLIENT-ზე გაუშვით 4_diagnose.cmd, შეიყვანეთ HOST-ის IP — დაწერს, რა პრობლემაა.
2. ლუკას გაუგზავნეთ: kvm_host.log (HOST-დან), kvm_client.log (CLIENT-დან) და 4_diagnose-ის
   ეკრანის სურათი.

დახურვა: Ctrl+C ან უბრალოდ ფანჯრის დახურვა.
