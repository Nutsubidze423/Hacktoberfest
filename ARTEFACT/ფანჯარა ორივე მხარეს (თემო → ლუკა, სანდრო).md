# ფანჯარა ორივე მხარეს: A → B და B → A, AnyDesk-ის მსგავსად

Claude, ეს ფაილი შენთვისაა (ლუკას ან სანდროს სესია). თემოს და გუნდს სურს, რომ ფანჯარა ორივე მიმართულებით გადადიოდეს. ქვემოთ წერია:
- რა არის უკვე მზად;
- რა აკლია და ვინ ფლობს;
- რაზე უნდა მიიღონ გადაწყვეტილება ლუკამ და სანდრომ.

## მიზანი

ფანჯარა (მაგ. Photoshop) კომპიუტერიდან, რომელზეც ის მუშაობს, მეორე კომპიუტერზე „გადადის“:
- **წყარო კომპიუტერზე** ფანჯარა ეკრანიდან ქრება, აპი იქ აგრძელებს მუშაობას. ის VDD-ზე დგას, როგორც დღეს A-ზე.
- **მეორე კომპიუტერზე** ფანჯარა ჩნდება ჩვენს viewer-ში: ჩვენი სათაურის ზოლით და ჩარჩოთი, როგორც ჩვეულებრივი ფანჯარა.
- **კლიკი, აკრეფა და სქროლი** viewer-ში ბრუნდება წყაროზე და იქ სრულდება, როგორც AnyDesk-ში, ოღონდ ერთ ფანჯარაზე.
- **მიმართულება:** A → B და B → A, ერთი და იგივე კოდით.

## რა არის მზად

**წყაროს მხარე: `WindowShare`** (`main`, `b0983e8`, თემო):
```cpp
auto share = kvm::WindowShare::start(hwnd, *video_channel,
    {.width = viewer_w, .height = viewer_h, .side = side, .jpeg_quality = q, .max_fps = fps});
// share->width()/height() -> stream_start;  share->monitor_rect() -> აქ ეცემა remote x_norm/y_norm
// share->alive() == false -> აპმა ფანჯარა დახურა ან VDD გაქრა
share.reset();   // sender -> capture -> ფანჯარა უკან -> VDD off; start()-ის შეცდომისასაც
```
ტესტი `tools/window_share_test.exe`: Paint VDD-ზე, 47 JPEG ~1.5 წმ-ში, ზუსტად ბრუნდება ადგილზე, VDD off.

**viewer-ის მხარე: სანდროს ბრენჩი `sandro/viewer-design`** (ჯერ `main`-ში არ არის):
- JPEG decoder (1080p ≈ 7 ms);
- Direct2D viewer საკუთარი სათაურის ზოლით, მდგომარეობის ეკრანებით და HUD-ით;
- video receiver (მხოლოდ ბოლო ფრეიმი, reconnect).

## ორივე მიმართულება: ლუკას გადასაწყვეტი

დღეს A არის host და აგზავნის, B კი client და ხედავს. B → A-სთვის ორივე პროგრამას ორივე ნაწილი სჭირდება:
- **CMake:** თემოს მოდულები (`capture`, `virtual_display`, `window_mover`, `jpeg_encoder`, `video_sender`, `window_share`, `remote_input`) `kvm_client`-საც უნდა ჰქონდეს, სანდროს viewer-ი კი `kvm_host`-საც. მაგალითად, ორივე ცალკე საერთო ბიბლიოთეკად.
- **შეტყობინებები:** `stream_start`/`stream_stop` და `remote_*` ორივე მიმართულებით იყოს დაშვებული. მიმართულებას ფანჯრის მფლობელი განსაზღვრავს. დაემატოს „ფანჯარა დამიბრუნე“ მოთხოვნა: viewer-ის დახურვა ან ღილაკი სათაურის ზოლზე.
- **ვიდეო არხი:** TCP ორმხრივია, ამიტომ იგივე `FrameChannel` ორივე მხარეს შეიძლება წაიკითხოს და ჩაწეროს. ალტერნატივაა მეორე კავშირი.
- **დემეტრეს KVM:** B-ზე VDD ისეთ მხარეს დადგეს, რომ KVM-ის კიდეს არ დაემთხვეს, ან VDD ჩართული იყოს მხოლოდ ფანჯრის გაზიარებისას (როგორც A-ზე).

## თემოს შემდეგი ნაბიჯი (თანხმობის შემთხვევაში)

`remote_input` + ტესტი: სინთეზური `remote_*` შეტყობინებებით Paint-ში, რომელიც VDD-ზეა, ხაზი დაიხატოს და ტექსტი აიკრიფოს, მერე ფანჯარა დაბრუნდეს. თემო `remote_input`-ს ცალკე ბრენჩზე იწყებს. ის `main`-ში შევა მხოლოდ თქვენი თანხმობის შემდეგ.
