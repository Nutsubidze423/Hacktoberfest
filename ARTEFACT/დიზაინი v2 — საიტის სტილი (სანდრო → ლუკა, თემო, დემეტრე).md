# აპის დიზაინი ახლა საიტს ემთხვევა (sarke-nine.vercel.app)

Claude, ეს ფაილი ყველა სესიისთვისაა. სანდრომ ითხოვა, რომ აპი საიტის დიზაინს დაემთხვეს. `docs/DESIGN.md` განახლდა (v2) — ის ისევ ერთადერთი წყაროა.

## რა შეიცვალა (ბრენჩი `sandro/website-design`)

- **ფერები:** საიტის პალიტრა (`globals.css`) — თითქმის შავი ფონი, `#1d1d1f` ფილები, ერთი ლურჯი (`#0071e3` ღილაკები, `#2997ff` ბმულები/ხაზები). ნარინჯისფერი აღარ არის. **ბნელი და ნათელი თემა** Windows-ის app mode-ს მიჰყვება (`SARKE_THEME=light|dark` აიძულებს).
- **შრიფტები:** Google Sans (ტექსტი) + Geist Mono (რიცხვები) — `assets/fonts/`-ში, OFL ლიცენზიებით (საიტის პაკეტებიდან). JetBrains Mono აღარ გამოიყენება.
- **ფორმა:** მომრგვალებული ფილები, pill ღილაკები, segmented control-ები, Windows 11-ის მომრგვალებული ფანჯრები სისტემური ჩარჩოს გარეშე. uppercase ლეიბლები აღარ არის — sentence case.
- **ლოგო:** საიტის ნიშანი (ორი გადაფარებული მომრგვალებული კვადრატი) ცვლის „ს caret“-ს — ხატულა, tray, ბარათი. `docs/brand/sarke.ico` ხელახლა გენერირდა.
- **სანდროს ზედაპირები:** viewer (status pill, ცენტრირებული ეკრანები keycap-ებით, HUD), Displays, შეტყობინების ბარათი, Identify, ბრაუზერის პრევიუები (`docs/preview/*`, 99 ტესტი).

## თქვენთვის

- **ლუკა:** `assets/fonts/` ახლა რეპოშია (Google Sans + Geist Mono). აპი შრიფტებს exe-დან ზემოთ ეძებს; `tools/make_test_package.ps1`-მა `assets\fonts` exe-ების გვერდით უნდა დააკოპიროს, თორემ Segoe UI-ზე გადადის. tokens/draw-ის `common/`-ში გადატანისას `client_b/ui_tokens_tmp.h` / `ui_draw_tmp.*` აიღე როგორც არის (თემა, `LayeredSurface`, `style_window`).
- **თემო:** window picker (DESIGN.md §3) ჯერ v1 სახელებს იყენებს. §2.2-ის ცხრილით გადაიყვანე: bg0→bg, bg1→tile, bg2→fill, textHi→ink, textMid→ink2, textLo→ink3, accent→accent_ink (ხაზები) / accent (ღილაკი). picker-ის footer-ში „Sarke“.
- **დემეტრე:** edge glow (§5) — ფერი accent_ink (`#2997ff` / ნათელში `#0066cc`).
