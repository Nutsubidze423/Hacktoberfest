# თემო: ფანჯარა B-ზე და უკან

Claude, ეს ფაილი შენთვისაა. ლუკამ თემოს შეთავაზება (`ARTEFACT/B როგორც მესამე მონიტორი.md`) წაიკითხა და გადაწყვეტილება მიიღო. ქვემოთ წერია, რა გადაწყდა, რა შემოწმდა ლუკას კომპიუტერზე და თემოს დავალებები თანმიმდევრობით. ჯერ ჩამოტვირთე `main`, მერე დაიწყე **T1**-ით.

## გადაწყვეტილებები

1. **დემოს მიზანი:** A-ზე ირჩევ **კონკრეტულ ფანჯარას**. ის A-ს ეკრანიდან ქრება და B-ზე ჩნდება, B-ზე **მხოლოდ ის ფანჯარა** ჩანს. ბრძანებით ფანჯარა A-ზე ბრუნდება. მთელი დესკტოპის სტრიმი არ არის მიზანი.
2. **VDD ფანჯრის „სადგომია“.** ფანჯარა გადადის ვირტუალურ მონიტორზე და იქ მაქსიმალდება, ანუ B-ს ეკრანის ზომის ხდება. ვიღებთ **VDD მონიტორს** (`CreateForMonitor`). იქ მხოლოდ ეს ფანჯარაა, ამიტომ B-ზე ის ჩანს თავისი მენიუებითა და დიალოგებით. ფანჯარა VDD-ზე „ცოცხალია“: DWM მას ხატავს, ხოლო `SendInput` ფოკუსის ხრიკების გარეშე მუშაობს.
3. **VDD ჩართულია მხოლოდ მაშინ, როცა ფანჯარა B-ზეა გაგზავნილი.** ის A-ს მარჯვნივ დგას, ზუსტად იქ, სადაც დემეტრეს KVM-ის კიდეა. ჩართული VDD-ის დროს მაუსი VDD-ზე იმ ფანჯარაზე მოძრაობს, რომელიც B-ზე ჩანს. გათიშული VDD-ის დროს დემეტრეს KVM კიდით მუშაობს. ამიტომ attach და detach (**T2**) აუცილებელია.
4. **Codec:** ჯერ **JPEG** (TurboJPEG), H.264 მოგვიანებით.
5. **`protocol.h` რჩება v1.** `stream_start.hwnd` არის გაგზავნილი ფანჯრის HWND, `width`/`height` VDD მონიტორის ზომა. `remote_*`-ის `x_norm`/`y_norm` ითვლება VDD მონიტორის მიმართ. კომენტარებს ლუკა შეასწორებს.
6. **CLAUDE.md-ში IddCx ჯერ ისევ „არ შედის“ სიაშია.** ეს მოძველებულია, ლუკა განაახლებს. მანამდე ეს ფაილი ჩათვალე წყაროდ.

## ვიდეოს არხი: ლუკას API (ლუკა ახლა წერს)

`common/include/kvm/video.h` main-ში ~1 საათში გამოჩნდება. **ეს სახელები საბოლოოა**, ამიტომ `video_sender` მათზე წინასწარ დაწერე:

```cpp
namespace kvm::net {
struct Frame {
    proto::FrameHeader header;           // seq, t_capture_us, width, height, codec
    std::vector<std::uint8_t> payload;   // encoded image (JPEG)
};
class FrameChannel {                     // one TCP connection on port 50501
public:
    bool send_frame(const proto::FrameHeader& header, std::span<const std::uint8_t> payload);  // thread-safe; false = closed
    std::optional<Frame> recv_frame();   // B side; nullopt = closed
    bool is_open() const;
    void close();
};
class VideoServer {                      // A: listens on 50501
public:
    explicit VideoServer(std::uint16_t port);
    std::unique_ptr<FrameChannel> accept();   // blocks; nullptr after stop()
    void stop();
};
std::unique_ptr<FrameChannel> connect_video(const std::string& host, std::uint16_t port,
                                            std::chrono::milliseconds timeout = std::chrono::seconds(2));
}  // namespace kvm::net
```

- `t_capture_us` აიღე `kvm::steady_now_us()`-ით (`kvm/net.h`). ამავე საათით ითვლის სანდრო latency-ს.
- `send_frame` სანამ ფრეიმს გააგზავნის, მანამდე ბლოკავს. ამიტომ `video_sender` ცალკე thread-ზე იყოს და ფრეიმები `LatestSlot`-იდან აიღოს: სანამ ერთი იგზავნება, ახალი ძველს ჩაანაცვლებს.
- სერვერის გაშვება და `stream_start`-ის გაგზავნა `main.cpp`-ში ლუკას საქმეა. შენ მხოლოდ `FrameChannel&`-ს იღებ.

### T2. `host_a/virtual_display.*`
- `find()`: `EnumDisplayDevicesW`, `DeviceString == L"Virtual Display Driver"`. აბრუნებს device name-ს, მაგ. `\\.\DISPLAY4`. ეს ნომერი კომპიუტერზეა დამოკიდებული, **კოდში ნუ ჩაწერ**.
- `set_mode(w, h, hz)`: ზემოთ მოცემული კოდით.
- `place(side)`: `right`/`left`/`top`/`bottom` დანარჩენი ჩართული მონიტორების კიდეების მიხედვით, `DM_POSITION`-ით. primary რჩება (0, 0)-ზე.
- `attach()` და `detach()`: მონიტორის დესკტოპზე ჩართვა და გათიშვა. detach-ის ცნობილი ხერხია `DM_POSITION | DM_PELSWIDTH | DM_PELSHEIGHT` და `dmPelsWidth = dmPelsHeight = 0`. attach-ისთვის რეჟიმი და პოზიცია ხელახლა დაყენდება. **ორივე ჯერ შესამოწმებელია.** თუ არ იმუშავა, აღწერე და ლუკას მისწერე. ალტერნატივაა `SetDisplayConfig`.
- `rect()`: მონიტორის rect ფიზიკურ პიქსელებში და `HMONITOR` (capture-სთვის).
- `tools/vdd_test.cpp`: ჩამოთვლა → 1920×1080 მარჯვნივ → detach → attach → ყოველი ნაბიჯის ლოგი.
- ✅ თემოს ლეპტოპზე გადის. მერე იგივეს ლუკა გაუშვებს A-ზე.

### T3. `host_a/window_mover.*` (ახალი)
- `send(hwnd, monitor_rect)`: შეინახე `WINDOWPLACEMENT`. თუ ფანჯარა მაქსიმალებული ან ჩაკეცილია, ჯერ აღადგინე (`SW_RESTORE`). მერე `SetWindowPos` მონიტორის კუთხეზე და `ShowWindow(SW_MAXIMIZE)`. თუ მონიტორებს სხვადასხვა DPI აქვთ, ჯერ გადატანა, მერე მაქსიმალება.
- `restore(hwnd)`: `SetWindowPlacement` შენახული მნიშვნელობით.
- ელევირებულ (Admin) ფანჯარას ჩვეულებრივი პროცესი ვერ გადაიტანს (UIPI). ასეთ შემთხვევაში დააბრუნე შეცდომა და ლოგში ჩაწერე „run kvm_host as admin“.
- ✅ Notepad და Paint გადადის VDD-ზე, ავსებს მას და ზუსტად ძველ ადგილას ბრუნდება.

### T4. `host_a/capture.*`
- WGC: `IGraphicsCaptureItemInterop::CreateForMonitor(HMONITOR)`. დაამატე `CreateForWindow`-იც, ეს ერთი ხაზია.
- `Direct3D11CaptureFramePool::CreateFreeThreaded`, `FrameArrived`, staging texture და BGRA.
- `IsCursorCaptureEnabled(true)`: A-ს კურსორი B-ზე უნდა ჩანდეს. `IsBorderRequired(false)` გამოიყენე, სადაც ხელმისაწვდომია (Win11). Win10-ზე ყვითელი ჩარჩო რჩება, ეს მისაღებია.
- გამოსავალი: `LatestSlot<CapturedFrame>`, სადაც `CapturedFrame { int width, height, stride; std::vector<std::uint8_t> bgra; std::int64_t t_capture_us; }`.
- `FrameArrived` callback-ში მძიმე სამუშაო არ გააკეთო. მხოლოდ კოპირება და `put()`.

### T5. `host_a/jpeg_encoder.*`
- TurboJPEG `tj3Compress8` (ან `tjCompress2`), `TJPF_BGRX`, 4:2:0, ხარისხი `config.json`-ის `jpeg_quality`-დან.
- გაზომე ms/ფრეიმი 1920×1080-ზე და ჩაწერე ლოგში.
- ✅ < 15 ms ლუკას Intel UHD 620-იან კომპიუტერზე, ან ჩაწერე, რამდენი გამოვიდა.

### T6. `capture_test` სრული ჯაჭვით
ფანჯრის არჩევა → `virtual_display`: attach, B-ს ზომა, მარჯვნივ → `window_mover::send` → 10 ფრეიმი `captures/*.jpg`-ში → `restore` → `detach`.
✅ JPEG-ებზე მხოლოდ ეს ფანჯარაა, მენიუს გახსნისას მენიუც ჩანს, და ტესტის შემდეგ A-ს დესკტოპი საწყის მდგომარეობაშია.

### T7. `host_a/video_sender.*`
ცალკე thread: `LatestSlot<CapturedFrame>::take()` → encode → `FrameChannel::send_frame()`. `seq++`, `codec = "jpeg"`. ზედა ზღვარი `max_fps` (config). `overwritten()` და encode-ის დრო ლოგში ყოველ 5 წმ-ში.
✅ კომპილირდება ლუკას `video.h`-ზე. ინტეგრაციას `main.cpp`-ში და სანდროს viewer-თან ლუკა გააკეთებს.
