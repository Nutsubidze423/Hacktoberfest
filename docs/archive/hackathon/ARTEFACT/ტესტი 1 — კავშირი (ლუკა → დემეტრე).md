# ტესტი 1: ორი კომპიუტერის კავშირი

Claude, ეს ფაილი შენთვისაა. დემეტრე და ლუკა ახლა ატარებენ პირველ ტესტს ორ ნამდვილ კომპიუტერს შორის. შენი ამოცანაა, დემეტრეს კომპიუტერი ამ ტესტისთვის მოამზადო და დაეხმარო, რომ ის ლუკას კომპიუტერს დაუკავშირდეს. ამ ტესტის დროს საკუთარ ტრეკზე (`dpi`, hooks) ნუ იმუშავებ, ის ტესტის შემდეგ გააგრძელე.

## რას ვამოწმებთ

მხოლოდ ქსელურ კავშირს: TCP 50500 პორტზე, `hello`, ყოველ წამში `ping`/`pong`, ხელახალი დაკავშირება და გაწყვეტილი კავშირის აღმოჩენა. მაუსი, კლავიატურა და ვიდეო ამ ტესტში ჯერ არ არის.

| როლი | კომპიუტერი | რას უშვებს |
| --- | --- | --- |
| **HOST (A)** | ლუკა | `kvm_host.exe`, უსმენს 50500 პორტს |
| **CLIENT (B)** | დემეტრე | `kvm_client.exe --host <ლუკას IP>` |

- **ლუკას IP:** ახლა `172.20.10.14`. hotspot-ზე IP შეიძლება შეიცვალოს, ამიტომ ზუსტ მისამართს ლუკა თავისი `2_run_host.cmd` ფანჯრიდან გეტყვის.
- **ქსელი:** ორივე კომპიუტერი ერთ ქსელზეა, **„Demetre's iPhone 2“** hotspot-ზე. Windows ამ ქსელს Public-ად აღიქვამს. ლუკას firewall-ის წესი ამასაც ფარავს.

## main-ის მდგომარეობა (`93c7e45`)

- `common/net.*` (ლუკა): `Connection`, `Server`, `connect()`. ping ყოველ 1 წმ-ში, კავშირი მკვდრად ითვლება 5 წმ სიჩუმის შემდეგ, B თავიდან ცდის ყოველ 1 წმ-ში.
- `host_a/main.cpp`, `client_b/main.cpp` (ლუკა): `hello` და პროტოკოლის ვერსიის შემოწმება (`kProtocolVersion = 1`), ყოველ 5 წმ-ში ლოგში `link: rtt ...`.
- `common/win32_input.*` (დემეტრე): უკვე main-შია და ლუკას კოდთან ერთად აიწყო.
- `tools/make_test_package.ps1`: ააწყობს exe-ებს და ქმნის `dist\kvm-test-<commit>\` საქაღალდეს, სადაც გასაშვები სკრიპტებია.

## ნაბიჯები (შენ ასრულებ, დემეტრე უყურებს)

1. **დაუკომიტებელი ცვლილებები:** გაუშვი `git status`. თუ დემეტრეს დაუკომიტებელი ცვლილებები აქვს, **ჰკითხე** commit ჯობია თუ `git stash`. თავად არაფერი წაშალო.
2. **main-ის ჩამოტანა:**
   ```
   git checkout main
   git pull origin main
   git log --oneline -1
   ```
   commit უნდა იყოს `93c7e45` ან უფრო ახალი. **ორივე მხარე ერთი და იმავე commit-იდან უნდა აიწყოს**, თორემ host ლოგში დაწერს „protocol vN but this host speaks vM“.
3. **Build და პაკეტი:**
   ```
   powershell -ExecutionPolicy Bypass -File tools\make_test_package.ps1
   ```
   ბოლოს ბრძანება წერს `Package: ...\dist\kvm-test-<commit>.zip`-ს. თუ build ჩავარდა, შეცდომა დემეტრეს აჩვენე. build-ის გამოსასწორებლად ლუკას ფაილებს ნუ შეცვლი.
4. **ქსელის შემოწმება:** დაადასტურე, რომ დემეტრე „Demetre's iPhone 2“-ზეა (`Get-NetConnectionProfile`) და მისი IP `172.20.10.x` დიაპაზონშია.
5. **ლუკას დადასტურება:** დაელოდე, სანამ ლუკა იტყვის, რომ `2_run_host.cmd` გაშვებულია. მის ფანჯარაში უნდა ეწეროს `listening on port 50500`.
6. **client-ის გაშვება:** დემეტრემ თავად დააწკაპუნოს ორჯერ `dist\kvm-test-<commit>\3_run_client.cmd`-ზე და შეიყვანოს ლუკას IP. ასე ფანჯარა ხილული დარჩება. შენ თვითონ ნუ გაუშვებ: პროგრამა გაჩერებამდე მუშაობს, და `.cmd`-ის ბოლოს `pause` დგას. ლოგი ჩაიწერება იქვე, `kvm_client.log`-ში. მისი წაკითხვა ნებისმიერ დროს შეგიძლია.

## თუ არ უკავშირდება

ჯერ გაუშვი `dist\kvm-test-<commit>\4_diagnose.cmd <ლუკას IP>`, ან პირდაპირ `Test-NetConnection <IP> -Port 50500`.

| ლოგში / diagnose-ში | ნიშნავს | რა ვქნათ |
| --- | --- | --- |
| `10060` (timed out) ან „Host not reachable“ | პაკეტი ვერ აღწევს | სხვადასხვა ქსელი, არასწორი IP, ან ლუკას firewall. ლუკამ ხელახლა გაუშვას `1_allow_firewall.cmd` |
| `10061` (refused) ან „port 50500 is closed“ | ლუკასთან არაფერი უსმენს | ლუკამ გაუშვას `2_run_host.cmd` |
| `protocol vN but this host speaks vM` | სხვადასხვა commit-ია | ორივემ `git pull` და build თავიდან |
| `no hello within 3 s` host-ზე | host-ს `Test-NetConnection` ან სხვა პროგრამა დაუკავშირდა | ნორმალურია, ყურადღებას ნუ მიაქცევ |
| connected, მერე მალევე `no data ... dropping` | ქსელი პაკეტებს კარგავს | სცადე ტელეფონთან ახლოს. hotspot-ზე ეს ჩვეულებრივია |

**ქსელურ კოდს ნუ ასწორებ.** `net.*`, `main.cpp`, `protocol.h` და `tools/` ლუკას ფაილებია. თუ კოდის ხარვეზი გგონია, აღწერე და ლუკას გაუგზავნე: ლოგის ხაზი, რა მოხდა და რას ელოდი.

**ასევე ნუ:**
- შეცვლი `config.json`-ის `host_ip`-ს. IP-ს `--host`-ით ან სკრიპტით გადავცემთ;
- დაამატებ `dist/`-ს git-ში (ის `.gitignore`-შია);
- შეეხები `ARTEFACT/`-ის სხვა ფაილებს.

## ტესტის შემდეგ

დაუბრუნდი დემეტრეს ტრეკს, `docs/PLAN.md` → „დემეტრე“. შემდეგი პუნქტებია `dpi.*` და `input_capture.*` (hooks + `Ctrl+Alt+Shift+Q`).

გაითვალისწინე, რომ თემომ შესთავაზა B იყოს A-ს ვირტუალური მესამე მონიტორი (`ARTEFACT/B როგორც მესამე მონიტორი.md`). ლუკას ჯერ არ გადაუწყვეტია. თუ მიიღებს, B-ს საკუთარი დესკტოპის KVM სავარაუდოდ hotkey-ით ჩაირთვება და არა ეკრანის კიდით. hooks, suppress, გადაუდებელი ღილაკი და `input_inject` ორივე შემთხვევაში საჭიროა, ამიტომ მათზე მუშაობა უსაფრთხოა. კიდის აღმოჩენას (edge detection) ჯერ ბოლოსთვის ტოვებ.
