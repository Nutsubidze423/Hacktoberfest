# Hackathon archive (October 17–18, 2026)

How Sarke was built at the hackathon by four developers, each with their own AI coding session, kept
unchanged for history. Most of it is in Georgian. Nothing here is current: the plan is
[docs/ROADMAP.md](../../ROADMAP.md) and the working rules are in [CONTRIBUTING.md](../../../CONTRIBUTING.md).

- `PLAN.md`: roles, deadlines and checklists per developer.
- `BLUEPRINT.md`: the catalogue of every feature, button, setting and Windows operation.
- `ARTEFACT/`: hand-off notes between the developers (decisions, tasks, test instructions).
